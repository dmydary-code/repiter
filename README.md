# Репитер 🦜

Телеграм-бот для заучивания слов методом интервальных повторений.

Кидаешь боту слово — он в случайные моменты дня присылает его в смешном
предложении, где слово выделено жирным, а перевод спрятан под спойлер.
Под каждым сообщением две кнопки: **Я выучила** двигает слово дальше по
лесенке интервалов, **Ещё хочу потом** возвращает на шаг назад.

Живёт целиком в GitHub Actions: постоянного сервера нет, состояние хранится
в `data/state.json` и коммитится обратно в репозиторий после каждого запуска.

---

## Как устроены интервалы

Лесенка собрана из классической схемы SM-2 / «1–3–7–14–30» плюс два коротких
шага в первый день — именно там кривая забывания падает круче всего.

| Шаг | Интервал |
|-----|----------|
| 1 | 25 минут |
| 2 | 4 часа |
| 3 | 1 день |
| 4 | 3 дня |
| 5 | 7 дней |
| 6 | 14 дней |
| 7 | 30 дней |
| 8 | 90 дней → архив |

Момент «пора повторить» — это не момент отправки. Бот дополнительно
раскидывает показ на случайное время внутри твоего дневного окна
(по умолчанию 10:00–22:00 МСК), поэтому сообщения приходят непредсказуемо
и никогда ночью. Максимум 8 напоминаний в день и не больше 2 за один запуск.

Если на сообщение так и не нажали кнопку, бот переспросит через сутки.

## Установка

### 1. Бот в Telegram

Напиши [@BotFather](https://t.me/BotFather) → `/newbot` → придумай имя
(`Репитер`) и юзернейм (например `repiter_words_bot`). Он выдаст токен вида
`123456789:AAF...` — это `TELEGRAM_BOT_TOKEN`.

### 2. Ключ xAI

Заведи ключ в консоли [console.x.ai](https://console.x.ai) — это `XAI_API_KEY`.
Модель по умолчанию `grok-4.6`; сменить можно переменной репозитория `XAI_MODEL`.

Расход крошечный: примерно 300–500 токенов на одно напоминание,
то есть меньше доллара в месяц при обычном темпе.

### 3. Секреты репозитория

Settings → Secrets and variables → Actions → New repository secret:

- `TELEGRAM_BOT_TOKEN`
- `XAI_API_KEY`

### 4. Запуск

Actions → **repiter tick** → Run workflow. Дальше расписание работает само.
Напиши боту `/start` в Telegram, выбери язык — и можно кидать слова.

## Важные оговорки

**Задержка.** GitHub Actions не держит постоянное соединение с Telegram —
он просыпается по расписанию раз в 15 минут. Значит, новое слово и нажатие
кнопки бот увидит не мгновенно, а в течение 5–20 минут. Для напоминалки это
незаметно, для живого диалога было бы неудобно.

**Лимит минут.** У приватного репозитория 2000 минут Actions в месяц.
Текущее расписание — 55 запусков в сутки, около 1650 минут. Если станет
тесно: проредить cron в `.github/workflows/tick.yml` или сделать репозиторий
публичным (там минуты безлимитны, но список слов станет виден всем —
токены останутся в секретах в любом случае).

**Сон расписания.** GitHub отключает cron в репозитории, где 60 дней не было
активности. Бот пишет в состояние поле `heartbeat` с текущей датой, так что
как минимум один коммит в сутки есть всегда.

**Точность cron.** GitHub не гарантирует запуск минута-в-минуту, при высокой
нагрузке запуск может сдвинуться или пропуститься. Пропущенный тик не теряет
напоминания — они просто уедут на следующий.

## Команды

| Команда | Что делает |
|---------|-----------|
| просто текст | добавить слово (несколько — с новой строки или через запятую) |
| `/list` | что сейчас в работе и когда следующий показ |
| `/stats` | сколько закрыто, сколько в работе |
| `/lang` | сменить язык (английский / французский) |
| `/window 10 22` | часы, в которые можно писать |
| `/limit 8` | максимум напоминаний в день |
| `/delete слово` | убрать слово |
| `/pause`, `/resume` | тишина и обратно |

## Структура

```
bot/
  main.py     один «тик»: разбор апдейтов + рассылка
  srs.py      лесенка интервалов и рандомизация времени показа
  grok.py     генерация примеров через api.x.ai
  render.py   тексты сообщений, выделение слова, спойлеры
  store.py    состояние в JSON
  tg.py       клиент Telegram Bot API (только стандартная библиотека)
tests/
  test_flow.py  прогон всего сценария на заглушках
data/
  state.json  состояние (коммитится ботом)
```

Зависимостей нет — всё на стандартной библиотеке Python 3.12,
поэтому запуск в Actions занимает секунды.

## Локальный прогон

```bash
python -m tests.test_flow          # 51 проверка на заглушках, сеть не нужна
TELEGRAM_BOT_TOKEN=... XAI_API_KEY=... python -m bot.main   # один живой тик
```
